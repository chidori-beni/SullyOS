# 恐龙箱庭

当前实现核对：2026-09-11。

移动端优先的橡皮泥模型箱庭。入口在 SAR 活动室茶几上，也能从钓鱼收藏进入。没有咖啡店或战斗系统。面向用户的全设施流程和模型调用说明见 [SAR 活动室怎么玩](../../docs/sar-user-guide.md)。

## 庭院操作与物品互动

打开先看整座庭院，不自动选中恐龙。底部只有「布置／恐龙／来访」三个入口；首次有可收起的小引导。点恐龙打开轻量小面板，再换地方、换颜色或写一句。图鉴放在「恐龙」，全部事件放在「来访足迹」。

「正在」只是一句话，不要求行为标签或对象。留空时显示所在位置的小日常。自定义句子仍保留署名与历史，移动地图、换色和环境动画不会覆盖它；已有存档的行为和对象继续兼容。角色也可以只提供 stage + words 来续写，无需提供标签。

`dinosaurActivities.ts` 从保存的格位、朝向和附近摆件分配互动。玩具用品与纯装饰分开：野餐垫上啃饼干并掉碎屑、水洼/浅水交替抬脚溅水、花丛低头闻花且花朵轻晃、面对小树够叶子、帐篷门口或石旁蜷起来呼吸、木桩中央摇尾巴放哨。火山、栅栏、路牌和玩具小屋只作为装饰。蛋和骨架保持静态。每个互动物品同时分配给一只恐龙；不满足距离、朝向或占位条件就不触发。

互动摆件在场景中有小爪印入口与浅色光圈，可直接点开详情，再选「让恐龙来玩」。接着从收藏中选一只，程序预览可互动的空格，仍须用户确认。 来玩列表在点击前说明可用、满员、占用或静态藏品。详情入口与场景入口共用 `planGardenPlay`，会搜索全部八个朝向；旧自由摆件没有可用格子时，可预览恐龙与这件未被占用的摆件一起调整，确认后在一次存档事务里保存两者，取消均不改变。不移动其他恐龙、不重置其他摆件。布置菜单提供对应摆件的小图和用途说明，不再通过文字列表选择目的地。

**所有添加、移动、转向都经过预览 → 调整位置/朝向 → 确定。** `dinosaurPlacement.ts` 的草稿只保留在当前组件，渲染副本不写入存档、计数或事件。格子标出可放和占用，选中物品发亮并显示朝向箭头；无效预览变红并禁用确认。取消或离开直接丢弃草稿；点确定后才在写锁内复核地图、修订号、所有权、容量和占位，并生成一次事件。其他页面/来访改变庭院时，旧草稿必须重新选择。新摆件只在确认后分配真实 ID。收起摆件有面板内二次确认。

**恐龙的位置和朝向始终固定在用户确认的数值。** 不再往返移动到摆件，也不自动转身。原地动作采用头、尾、脚三个轻量 morph 通道，保持身体、眼睛和颜色一起变形；摆件与饼干碎屑/水花给出相应反馈。木桩提供静态支撑高度。不会逐帧写存档或调用 LLM。固定开关仍表示禁止角色改动；「正在」的一句话不决定任意动画，角色提示词共用实际支持的环境互动。每图最多六只恐龙和十二件摆件。

## 地图与美术

- 溪边草原：草坡、溪流、木桥、花丛、蘑菇、彩旗、营地。
- 贝壳海岸：弧形沙滩、浅水湾、棕榈树、灯塔、遮阳伞、贝壳、海星、玩具帆船。没有桥或草原的栅栏和彩旗。
- 火山探险：灰褐色岩台、橡皮泥熔岩、晶簇、化石压印、探险补给、圆火山和烟团。没有溪流、桥或彩旗。

三张地图分别构图，共用底座与低成本几何生成器。每张地图独立保存摆件和恐龙位置，所有角色共用每图六个恐龙名额。当前开放三张地图；尚未接活动解锁更多主题。用户和现有角色的收藏可一起摆放，归属不因摆放而改变。

恐龙以用户参考图为依据离线生成 GLB：连续的圆润身体、哑光顶点色、保留眼睛和表情。原有十二种收藏及新增剧情专属混合恐龙均有模型，共十三种模型资产。UV 两通道作为身体和细节的换色权重，不需要贴图。六组配色及两个色盘只作用于当前单只；预览可取消。自由手绘尚未实现。

艾文三星事件的「？？？」使用稳定 `speciesId: aiven-chimera`：霸王龙身体、三角龙角、剑龙背板、腕龙长脖子与异常拼色。沿用橡皮泥 SDF 建模、图标、换色和原地动作系统；单网格 8,236 三角面、约 301 KiB，剧情近看与箱庭按需加载同一 GLB。它是明确赠送一次的真实收藏，名册回看只有演出，不重新发放；不进入垂钓、普通随机赠礼或蛋的孵化池。

恐龙蛋从随机垂钓池移除，新档由艾文三星话题赠送并开放对应图鉴。旧档已持有或历史获得的蛋继续可见与使用；孵化六小时后手动揭晓标准活体恐龙，蛋和骨架本身保持静态。十三种模型资产不等于十三种当前可钓藏品，也不等于所有用户图鉴始终显示相同总数。

## 隐藏棋盘

`dinosaurGrid.ts` 固定 A～F 六行、每行五格。恐龙位置吸附到这三十个落点，朝向量化为八个方向。平常不显示棋盘；摆放时显示方格轮廓与有效/占用颜色。每只只占一格，每图最多六只，摆件会封锁附近落点。灯塔、遮阳伞等固定布景也使用共用地标位置校验占位，手动摆放、角色动作和旧自由坐标迁移都会避让。用户可跨地图移动同一只恐龙，不产生副本。

角色模型可以输出具体 `slotId`，或 `anchorId + near/face`。代码负责查找空格、占位、摆件避让和朝向；任意自由坐标不进入执行器。新手动摆件同样吸附棋盘，已有的自由摆件坐标不会在打开存档时被强制改写；调整时仍检查边界和碰撞。

## 身份、记录与存档

所有内容在既有 `vr_fishing_market_v1` 的 `dinosaurGarden` 中，完整进入原 SAR 本地备份。没有新的远端数据库。首次打开只赠送一只真实收藏项；账本标记避免反复领取，来源明确记录为艾文的赠礼。

个人线进度与奖励收据存于同一市场记录的 `sarFamiliarity`，其恐龙赠礼进入共用库存，不另建展示用背包。首次箱庭赠礼与剧情赠礼分别去重。完整 ZIP 保留相关个人线纪念照片；纯文字备份保留箱庭、收藏、个人线文字与进度，去掉图片内容。

单只身份绑定 `FishingCatch.id`，保留名字、配色、获得者/来源、原始用户状态、当前状态、地图/格位、固定状态和修订号。同种多只完全独立；赠送保留身份和经历，并向受赠角色写入事实回执。挂板或孵化中的藏品不能摆放；图鉴发现记录和当前持有数量分开。

用户可直接留一句小剧场；旧版十二种行为和对象字段保持兼容。来访只追加当前状态和署名，不修改用户原文。事件历史不裁剪；可回复便签、定位恐龙、回看旧位置。还原仅在目标之后没有变化、旧位置仍空闲时允许，且追加还原事件，不抹去来访记录。

早期单桌预览会迁移为多地图，旧自由位置吸附到不冲突的格位，个体信息保留。损坏/未知结构不会被初始化覆盖，原始内容仍能通过既有备份导出。Web Locks 串行化本页和其他标签页的写入；验证抛错后也必须释放锁。

## 角色来访的实际边界

真实入口使用 `runVRSession` 原有角色人格、上下文和 API 优先级。一次会话选择评论、移动或续写中的一个动作；固定恐龙只接受评论。执行时重新读取存档，核对地图、修订号、所有权、格位和共同摆弄开关。切换正在查看的地图不会把角色动作挪到另一张图。

自动来访挂在原有彼方在线活动调度中，每角色至少间隔十二小时，全局二十四小时最多三次；用户手动邀请不受自动频率限制。**关闭应用期间不会新产生来访**，没有实现后台 Worker 来访，也不补刷离线天数。试玩页使用明确标注的“示例来客”固定回复，不调用模型；生产入口才调用用户配置的模型。

## 性能与验证

只加载、显示当前地图所需模型；图鉴近看只显示单只。地形只在切换主题时重建，可编辑摆件按身份保留网格，移动和转向只更新变换。每种恐龙的动作通道在模板加载时计算一次，实例克隆独立几何与配色；互动粒子每只合为一个 InstancedMesh。场景爪印与地面光圈保留独立透明绘制，避免遮盖地形。

DPR 上限 1.4，绘图缓冲区同时限制在一百万像素内。只有原地互动、打招呼和视角阻尼需要持续画帧，上限 30 fps；静止近看、摆放预览和减少动态效果按需重画，图鉴完全遮住画面时暂停渲染与隐藏居民同步。512 阴影在布置变更时更新，动画期间最多每秒更新三次。离屏／后台停画，关闭显式释放几何、材质、纹理、实例缓存和 WebGL 上下文。无后处理或水面折射。

同一 390×844、DPR 2 浏览器场景（四只恐龙）采样：普通帧／阴影更新帧的绘制调用由 59／74 降到 44／59；静止近看、摆放和隐藏图鉴的采样区间均为零新增绘制帧。旋转摆件不增加地形或摆件几何生成次数，多次图鉴进出后 GPU 资源计数稳定。`qa-performance.mjs` 验证这些边界和宽屏像素预算，`qa-integration.mjs` 还检查退出入口后 WebGL 上下文释放。真机帧率尚未测量，不能把桌面模拟手机的结果当作真机性能保证。

单元测试：`dinosaurPlay.test.ts`、`dinosaurPlacement.test.ts`、`dinosaurActivities.test.ts`、`dinosaurGarden.test.ts`、`fishingMarket.test.ts`、`fishingSession.test.ts`。覆盖独立身份、每图六只、跨图搬家、格位/朝向、占位、模型动作、原文保留、固定/过期结果、还原、赠送、存储损坏与锁恢复、旧存档迁移、原有钓鱼回归。角色测试使用假 API。

浏览器：`prototypes/dino-cafe/qa-garden.mjs` 检查 390/320 竖屏、横屏、触控旋转、格位预览/取消/冲突/确认、换色/取消/刷新、一句话/空白默认状态、固定、场景摆件点选/环境互动、来访/还原、摆件引导、三地图与原有十二种模型。新增 `scripts/test-aiven-chimera-model.mjs` 单独检查混合恐龙 GLB、320/390/1100 px 近看与箱庭、换色、旋转、打招呼和减少动态效果。`qa-integration.mjs` 用真实 OS/Music Provider 检查 SAR → 箱庭 → 钓鱼收藏 → 箱庭，拦截远端请求。官方 web-game 客户端另跑实际帧推进与截图。测试截图、状态和构建产物在忽略的 `output/` 子目录。
