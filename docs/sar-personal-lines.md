# SAR 个人线

当前实现核对：2026-09-12。用户操作总览见 [SAR 活动室怎么玩](./sar-user-guide.md)。

常驻 NPC 关闭时，名册、专属纪念、NPC 专属图鉴条目以及角色称号显示和编辑全部隐藏，运行中的个人线与尚未投递的彩蛋暂停；聊天与活动不注入 NPC 背景或称号提示词。进度和原称号保留，重新开启后恢复。开关同页、跨页即时同步，已关闭后返回的角色活动不能写入新称号。旧聊天记录不删除。

凯恩与艾文的原稿目前覆盖一至三星。名册保留五颗星，四、五星不生成临时剧情。

艾文普通日常问候按「星期 → 时段 → 天气」排列，每组仍随机选一句，同一访问内保持稳定；星期使用用户设备的本地日期。

## 日常与回忆

- 点击常驻 NPC 先进入正常对话；艾文的问候或当前剧情读完后，再显示「卖鱼 / 离开」，沿用对话选项样式与收尾立绘，不增加前置菜单。星级事件先单独显示结束页，继续后再出现卖鱼选项。卖鱼直接打开自己的鱼获列表，沿用行情、额度、到账与艾文回执；名册回看不出现售鱼选项。NPC 隐藏时不显示相关选项，也不主动触发个人线。
- 两人分别按用户本地自然日抽取普通话题：80% 从当前篇章十个未完成话题中选一个，20% 不触发。刷新、切页、跨标签页不会重抽；时钟回拨不会额外产生机会。
- 本篇章十个普通话题全部完成后，下次点击角色才开始星级事件，无需等第二天；完成事件才升星。艾文已开放的星级彩蛋另有每天一次的独立 20% 抽取，不替代普通话题。「字变了」（A1-E07）必须在「不要再钓了」（A1-E06）完整结束后才会触发；抽取、旧待触发队列、开场与结算均校验前置关系。Sully 偶遇也独立检查在场条件与概率。多段同时抽中时，普通话题优先，其余保留到后续点击；已完成内容不重复。三星后只保留原稿已有彩蛋与偶遇，不补写四、五星。
- 正式游玩没有对话返回按钮；切走导致日常话题、星级事件和彩蛋中断后不算完成，下次点击从同一段开头重来，分支、表情与互动草稿重新开始。未读完的普通话题跨天重开也占当天话题名额。普通话题和彩蛋读完直接回房间；星级事件读完最后一句后，再点击才结算并进入独立结束页，显示「结束 X 星事件：标题」，保留末句表情，点击再离开，没有追加话题菜单。无事件时按时段、天气与星期抽取问候，逐句读完也直接退出。
- 星级事件完整结束才点亮对应星。Sully 偶遇只在本尊实际加入 SAR 时发生，内置 ID 优先，因此重命名不影响识别。
- 已完成内容收入「随身仓库 → 图鉴 → 名册 → 回忆」。回看使用独立内存游标，不写入进度、不发奖、不续限时优惠、不再发送私聊彩蛋。

名册的「人物档案」保留两人完整原文简介；回忆按星级事件、日常话题、彩蛋与遇见分组，未完成项只显示通用锁定标题。名册是用户与这两位 NPC 的进度，不随仓库切换到哪个角色而变化。回看返回名册；收藏、专属纪念、名册共用「收集图鉴」标题与三个固定标签，只切换下方内容，不另开层级。详情返回当前标签列表，标签根页返回随身仓库。

## 对话与镜头

个人线默认单人居中，另一位 NPC 实际发言后进入双人同框，并留到当前对话节点结束（包括接话和反应）。跨节点检查后续六句：仍有对方台词时保持同框，没有则恢复单人；选择尚未确定时，只保留已出场的人，不提前引入未出场角色。台词提及名字、设定听者表情不会触发首次出场。`guestPresent` 与原有游标一起保存，同一次阅读与回放遵循同一规则。凯恩初遇也使用这套留场规则。初遇中凯恩被拆台的 embarrassed 表情在他接下一句时触发。

取消对话顶部信息栏，人物名、星级集中在底部名字行；返回按钮只在名册回看显示，正式剧情与初遇隐藏；话题标题也放在这里，但仅在名册回顾时显示。初遇与日常统一为浅色全屏舞台，不留上下黑边；底部为固定高度的气泡，点击按句推进；时间、天气、星期问候也逐句显示。当前原稿台词读完才推进存档游标，句内分页不改变分支与奖励。读到选择点后，选项使用与当前界面同色的居中浮层，聚焦与悬停不改底色，不占底部布局或改变立绘大小。单人、双人、普通问候共用按舞台高度计算的缩放，两人统一缩小 15%，下缘与对话框对齐，不再额外下移。互动演出完成确认后才显示选项。

证件、合照、物品或恐龙等演出保持完整立绘与底部对话，物品只在对应的展示台词上进入立绘前方，点击继续后收起。`effectLine` 指定展示的原稿行（默认首行），未拿出物品时不抢先展示；展示行若接选项，先收起物品，再居中呈现选项。照片和成员证完成操作后才允许继续。收藏页仍可完整查看物品。玩家可随时离开，下次从这一段开头重新阅读。个人线来自固定原稿，不调用世界意志或 LLM 续写，与五十轮芯片演绎分别保存。

## 奖励与演出

剧情和奖励存于 `vr_fishing_market_v1.sarFamiliarity`，与钱包、模块、鱼获使用同一个加锁事务。本次阅读经过的节点先记入 `visitedNodes`，完整读完后统一结算进度和奖励；中断重开丢弃本次未结算的节点。每个已发奖励的节点保留唯一记录，重复点击和跨页竞争不会重复发放；旧档已入库的赠品保留并跳过重复发放。存储失败时整笔回滚。

- 凯恩：管理员证演出；经用户确认的成员证；随分支保存结论的会议记录；可调构图、缩放、取景、加入自家角色的合照；带用户标签的旧式存档卡。
- 艾文：猫科语法包、关键词消音器、随机标准恐龙、恐龙蛋、优惠券、隐藏称号、备用存档卡与专属 `aiven-chimera`。
- 三星物品堆是演出道具，只有明确赠送的物品入库。假称号、七折玩笑、加载失败提示也不产生真实资产。
- 券雨固定三张；礼炮、物品爆出和恐龙展示通过普通对话继续，不额外要求确认。成员证、拍照和神秘按钮保留实际操作。
- 折扣采用 30 分钟有效期：全店或当前货架随机一个商品八折。九折券按真实数量使用；不叠加，自动选择最佳单项，同价优先用限时折扣以保留券，金额向上取整且最低 1 鳞币。过期旧报价不会静默涨价扣款。
- 新档称号系统于艾文二星开放，获得的「听懂风的人」可在称号编辑器选用，不覆盖用户已有称号。旧档已有称号保留使用资格。
- 蛋由艾文三星话题送出并开放对应图鉴，退出随机垂钓池。旧档已有的蛋和历史收藏保留。专属混合恐龙不进入垂钓、普通随机赠礼或孵化池。
- Sully 彩蛋进入本地私聊消息队列，以固定投递 ID 去重，不调用模型。

## 素材与保存

17 张表情来自用户提供的 [SAR 素材仓库](https://github.com/qegj567-cloud/SullyOS-assets/tree/main/SAR)。凯恩支持 11 种、艾文支持 6 种合法表情；逐句选择，旁白保留上一个表情。凯恩新增 `Enduring Pain`（忍痛，原名含空格）、`avoidant`（回避）、`normal2`（平常2）、`warm`（温柔），可手动校对并随草稿、清单导出，已将 2026-09-12 用户校对清单写回原稿。`public/sar-portraits` 保留原画布比例，转为最大边 1500 px 的 WebP，合计 3,190,522 B（约 3.19 MB），原有 13 张素材及其透明信息保持不变。新增四张已同步素材提交 `01edb974` 的透明 PNG，重新生成 WebP 并更新缓存版本；既有表情标记保持有效。本地加载失败时回落原 CDN。

纪念物保存当时的姓名、日期、图片引用、构图和选择；后续更换形象不修改旧照片。在「仓库 → 图鉴 → 专属纪念」单独查看证件、照片、会议记录、存档卡与剧情专属恐龙，可按凯恩／艾文筛选，每页最多十二份；只展示真实获得的记录，转出的特殊恐龙仍保留历史收录。凯恩纪念物使用纸页、压印、相纸与旧式存储卡外壳的统一呈现，收藏缩略图为轻量静态物件，不运行剧情或 3D。仓库的「纪念」仍可打开同一份原物，「优惠券」显示真实未使用数量；它们不借用当前查看角色的钱包或背包。

完整 ZIP 的 `sarLocalState` 包含个人线与未完成草稿，嵌套 `blobref:` 经元数据扫描一并导出二进制图片，恢复时沿用原 token。纯文字备份剥离 `blobref:` 和内嵌图片，保留进度、纪念物文字、构图、分支、优惠及投递状态。备份包含奖励收据，因此恢复后继续阅读仍不会重复领奖。

## 验证

单测覆盖 84 个原稿场景的可达性、台词表情合法性、每日上限、空白日、十话题门槛、跨天重开、并发、存储失败、奖励归属、优惠过期和图鉴历史。浏览器脚本位于 `scripts/test-sar-familiarity-*.mjs`，覆盖真实 Root 流程、名册回看不写档、320/390/1100 px、合照与纪念物、神秘按钮以及 3D 模型。

开发预览仅用于隔离测试浏览器；不要在用户主浏览器打开带种子数据的测试 fixture。交付展示为 `output/fishing-qa/npc-lines/gallery.html` 静态截图集。

### 本地校对入口（默认关闭）

回顾左上角常驻「返回选项」，直接回到最近一次选项前，重选另一条分支；还没有选过分支时显示「返回上一步」。无需展开表情校对栏。分支结束后临时保留结束画面，仍可返回选项，点击对白才离开回顾；已保存的表情修改不会被回退。

`pnpm dev` 下先打开扳手，开启「SAR 剧情与表情校对」，「图鉴 → 名册 → 回忆」才临时开放凯恩、艾文的全部 84 段原稿，包括话题、六个星级事件、彩蛋和偶遇；四、五星没有原稿，不补出虚构条目。进入回顾后点右上角「表情校对」，可逐句选择发言角色的表情，灰色听者只读并提示跳回其台词修改，使用「上一句」「跳转台词」定位台词或分支，「恢复这句原表情」只撤销该句修改。名册和校对侧栏均提供「复制修改清单」「下载修改清单」，导出两人的全局 JSON，供后续核对并回写原稿数据。

开关默认关闭，关闭后收藏册立即恢复真实解锁状态，正在看的未解锁预览退出；已保存校对草稿仍保留。入口与读取权限同时受 `import.meta.env.DEV`、调试面板可用性与 `sarExpressionReview` 开关限定；生产构建一律不允许临时解锁，正式版手动打开调试面板也不能开启它。回顾游标、分支、证件确认和拍照草稿只存在内存，不修改星级、奖励、收藏、聊天或正式备份；离开后从头测试。表情修改单独存于按分支隔离的 `sullyos.devDebug.sarExpressionReview.v1.<branch>`，刷新后仍可继续校对，不改 `sarFamiliarity` 或原始剧情文件，也不加入 SAR 游戏存档备份。

`scripts/test-sar-event-preview.mjs` 从真实名册逐条打开全部 84 段并完整读完六个星级事件，核对正式市场存档不变、零模型调用，以及编译为 `DEV=false` 后全部拒绝临时预览。

### 台词与演出细节

姓名占位符统一解析为用户昵称（兼容 User 大小写及括号）；发现者记录、成员证、纪念物和对白共用解析，默认资料名 User 以「你」称呼，昵称中的美元符号按字面保留。

SAR 陈述句统一使用句号，问号、感叹号、省略号和括号动作保留各自语气；标题和按钮不追加句号。用户清单共 288 处，286 处直接写回；一处灰色听者修改遵循新规则，一处收尾修改由用户最新的开心台词覆盖。角色变灰时沿用其最后一次发言的表情，旁白也不换表情；只有轮到本人发言才按原稿切换，不强制按句数换脸。长台词可用 `sentenceExpressions` 指定拆句后的表情，存档保留末句表情。艾文拆台时不抢先切换凯恩的 embarrassed，留到凯恩的反应句。

展示物品时可点击物品或「放大查看」打开独立详情，关闭后停在原句，不确认领取、拍照或写入奖励。成员证使用正向文字与不参与滤镜栅格化的容器，确认按钮在证件下方。艾文的礼炮覆盖整个视口，有限时长且不阻挡操作，尊重系统减少动态效果设置。
