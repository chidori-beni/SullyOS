# 可选浏览器全屏

外观页的「浏览器全屏」提供一次手动进入 / 退出操作。状态以 `document.fullscreenElement` 和 `fullscreenchange` 为准，不写入主题或持久化开关，不会因开机、刷新、点空白或用户退出而自动请求。请求在按钮点击内立即发起，失败留在原界面并提示，原生 Capacitor 不显示该入口；不支持的浏览器禁用入口。

实现：`components/appearance/FullscreenSettings.tsx`。保留现有开机动画、浏览器返回守卫、iOS/PWA 视口处理与 `--safe-top` / `--chrome-top` / `--safe-bottom`。这些变量还负责硬件遮挡和应用自己的状态栏，不能因为隐藏浏览器工具栏就统一清零。其他游戏的全屏入口保持原状。

自动回归覆盖手动请求、外部退出后不重入、失败重试、退出已有全屏、不支持与原生平台。Android 真机仍需验证：进入/退出、返回手势、键盘弹出收起、横竖屏、刘海设备顶栏及底部按钮。桌面自动化不能代替这些设备验收。
