# SAR 叙事与世界意志

当前实现核对：2026-09-11。

用户提出的核心原则：**世界负责产生故事，用户负责决定如何生活在故事之中。** 世界可以比用户知道的复杂得多，复杂性由世界承担，理解成本由叙事负责消化，选择权留给用户。

## 产品要求

1. 用户是参与者，不承担编剧、推进主线或维持节奏的责任。参与、拒绝、忽略、离开与改变关注点都成立。
2. 无需理解也能参与。先呈现受影响的人、可感知事件、生活后果与当前意义，再解释复杂原因。
3. 渐进展开世界观。现象与后果 → 简单原因 → 设定细节 → 深层机制；仅随用户持续探索加深，停止追问就停止加深。
4. 镜头跟随当下关注。关系、亲密、日常、喜剧、探索、冒险与主线可以随对话切换，不设置用户必须选择的模式。
5. 没接住剧情时减轻信息负担。短回复只是弱信号；困惑先用普通话解释，明确拒绝优先于推测出的兴趣。
6. 角色拥有自己的判断、计划、私心与行动，不充当世界观考官，不把下一步的思考责任交给用户。
7. 事件首先是钩子。可以被别人处理、自然结束或以后产生新后果；拒绝后允许退场，不换说法重复催促。
8. 世界意志承担隐藏导演职能。用户看到可感知的故事，不看到调度分析、兴趣评分、秘密或未来剧情规划。
9. 主线不霸占生活。吃饭、陪伴和安静相处同样构成经历，世界意志可以选择什么都不打断。
10. 自由来自世界中真实存在的可能性。角色可以拒绝、离开、隐瞒与犯错；用户仍决定自己的行动、感受、台词和立场。
11. 目标是让用户想“这里正在发生事情，而我现在想做什么”，而不是“我该说什么才能让剧情继续”。

## 共同确认的边界

- 不把所有被忽略的事件改成亲近的人受伤、失踪来强拉主线；后果来自已建立的因果，不能惩罚用户没有接钩子。
- 保留所选模块的气氛与真实危险，不把所有题材改成日常。既有危险可以由角色应对，也可以产生合理后果。
- 故事时间不等于互动轮数，十句对话可能只过去两分钟。场外行动遵守时间、距离、能力和既有事实。
- 五十轮保留为产品篇幅与收束边界。收束实际参与的关系和经历，允许世界中的主线未解决。末轮可用既定返航机制关闭连接，不代写用户主动走进出口或接受某种结局。
- 旁白允许为空；内部记录只保存少量事实，不保存推理过程或用户人格评分。叙事自主在每次用户互动内完成，不增加后台自动调用。

## 实现

这套世界意志规则用于芯片铸造与五十轮生成式演绎。凯恩、艾文的 [个人线](./sar-personal-lines.md) 则按用户原稿运行固定分支，不交给世界意志补写、不新增模型调用，也不沿用五十轮计数。个人线每日机会按本地自然日记录；推演中的故事时间仍遵守当前场景，不能把二者混为一套时钟。

个人线只在用户点 NPC 后进入，支持离开、断点续读和已完成回忆重看，不打断其他玩法。五颗星只实现有原稿的一至三星，四、五星保持未开放。镜头默认本人单人居中，对方实际发言后保持当前小段双人同框；跨节点查看后续六句是否还有对方台词，避免轮流说话时反复退场。叙述延续最近说话者。台词逐句点击推进，选项居中浮现，不挤占立绘。初遇被拆台的尴尬表情在凯恩接话时揭示。特殊演出仍保留当前人物情绪，赠品只按程序确认的奖励入库，回放不重发。

`utils/vrWorld/sarNarrative.ts` 提供统一运行规则，以及有界的 `sceneFacts / openThreads / offscreenFacts / declinedHooks / revealedFacts` 快照。每项最多六条，每条最多 180 字。缺失或不完整快照不覆盖最后一份有效记录。

铸造、运行和五十轮阶段统一遵循上述规则；旧卡的强制任务描述只作为初始背景参考，已发生事实保留。世界与角色在同一次模型请求中生成，连续性快照保存在该回复的消息元数据里。空旁白正常解析；损坏的结构化输出报错，避免将内部字段显示为正文。

身份卡默认展示简介与开场；背景折叠，不展示隐藏真相和预设抉择。演绎以正文为主，资料、主题、进度与封存进入次级页面。封存正文导出只含用户可见内容。

## 验证范围

单元与浏览器检查覆盖空旁白、私有记录、旧文本回退、损坏 JSON、刷新续写、失败不计轮、封存与五十轮结尾、主题、小屏和重读位置。浏览器使用独立存档和模拟模型回复；它验证程序契约，不代表所有真实模型的叙事质量已被评测。
