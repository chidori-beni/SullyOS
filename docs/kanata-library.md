# 彼方书库与分类阅读

书库支持按书名、作者搜索，按分类筛选，每页显示 12 本。常用操作只有「上架」「分类」「整理」：分类中创建、重命名或移除分类；整理中勾选书籍、选择本页，并批量移入分类。每本书归属一个分类；旧书默认未分类。移除分类只把书放回未分类，不删除正文、书签或批注。书籍下架仍会删除对应批注，需单独确认。

在某个分类下点上架，会默认选中该分类；上架弹窗也可以改选。TXT、PDF 与粘贴正文沿用原导入流程。

## 角色阅读偏好

入口为书库底部「谁来读这些书」，或「接入」里的角色阅读偏好。三种方式：

- **全部轮换**：在全书库尚未读完的书中轮换；都读完后重读。
- **按分类**：可选择多个分类，只在这些分类的并集中轮换。新归入的书自动加入，不需要再次修改角色偏好。读完后在这些分类内重读；分类为空、未选分类或所选分类已被移除时，暂停图书馆阅读，不回退其他书。其他彼方活动照常运行。
- **逐本优先**：保留旧规则，先在圈定的书中读，读完后回到全书库；没有指定书时等同全部轮换。

每种方式保留自己的选择，切换方式不会擦掉另外一种选择。有多个候选时排除上次读的书，避免连续两轮重复。每本书的角色书签和批注保持独立。

## 存储与实现

- `VRWorldNovel.categoryId` 保存分类的稳定 ID。
- 分类 `{ id, name }` 存在现有 IndexedDB `vr_settings` 的 `library-categories-v1` 记录中，不新建数据库或 localStorage 副本。空分类也能保存，重命名不改变 ID。
- `VRWorldCharState.novelReadingMode` 为 `all / categories / books`；分类选择为 `preferredNovelCategoryIds`，逐本选择仍为 `preferredNovelIds`。旧档缺模式时，有逐本选择则沿用 books，否则 all。
- `DB.editVRLibrary` 在同一读写事务中读最新分类与书籍、校验操作、保存分类和书籍归属；失败整体回滚，不写入部分移动结果。正文、创建时间、批注与角色记录不被整理操作覆盖。
- 全量备份已有的 `vrNovels`、`vrSettings` 和角色记录覆盖这三部分；恢复沿用原字段透传。删除分类不自动清掉角色的分类 ID，避免意外变成全书库；偏好页显示失效选择，用户可清除或重新选择。
- `utils/vrWorld/library.ts` 集中分类校验及阅读范围；`runSession.ts` 的手动和自动阅读都使用同一规则。没有候选时，自动活动池不放入图书馆；手动指定图书馆也不偷偷换房间。
- 活动生成期间更新偏好，以保存时的最新角色偏好为准，避免旧会话结果覆盖新范围；已经开始的一次阅读可能仍完成原书本轮批注。
- UI 位于 `apps/vrWorld/VRLibrary.tsx` 和 `vr-library.css`。偏好弹窗共用 iOS 顶部、底部安全区，正文独立滚动。
