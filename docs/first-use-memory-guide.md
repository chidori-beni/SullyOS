# 首次使用：API 与记忆引导

在角色库成功读取、尚未插入内置 Sully 时判断是否首次使用。只有空角色库且没有引导标记时自动开始；已有用户标记完成，不弹新手流程。读取 DB 失败时不做新用户判断。

`os_first_use_memory_guide_v1` 保存 0–6 的步骤或 `done`，刷新后从原步骤续接。引导挂在 `PhoneShell` 的 App 容器外，跨 App 保留，可折叠且不遮挡表单。免责声明、导入恢复提示仍优先；周年赠礼和版本公告等待引导完成。

1. 自动打开设置、展开 API 配置，保存完整 URL / Key / 模型后可继续。
2. 引导期间只显示副 API 与 Embedding API 两个配置区，隐藏全局页面的其它选项。全自动记忆需要两者均完整配置；副 API 可点击「我想暂时只用主 API」，复制主 API 配置用于文字整理，不调用模型。Embedding 区提供「暂时跳过向量记忆」：完成副 API 选择即可跳过，直接进入聊天教学，不开启记忆开关。跳过状态通过 `os_first_use_skip_vector_v1` 持久化，流程显示为六步，结尾明确提醒稍后补配；返回第二步并完成两项配置后可恢复七步完整流程。提供硅基流动网页版实名认证提示，也允许熟悉 Embedding 的用户自行配置兼容服务。
3. 回到记忆宫殿角色列表，圈出 Sully 的记忆开关，等待用户主动开启记忆宫殿与全自动记忆。
4. 打开神经链接，由用户点 Sully、发消息进入聊天。
5. 圈出实际聊天生成按钮，仅介绍位置及费用，不点击生成，不发送测试消息。
6. 返回桌面，必须观察到桌面已渲染，再等待用户点击聊天 App。
7. 解释自动整理、原始文字档案与向量记忆的区别、神经链接的编辑入口，以及聊天加号设置中手动向量化并非常规操作。

配置门禁只判断已保存的必填字段，不声称服务连通，不自动发起 API 测试。所有记忆开关沿用原有处理函数，引导不额外改写角色记忆策略。

每一步都有「直接跳过引导」，收起后仍显示。点击即持久化完成状态，停留当前页面、不改已有配置、不自动开启记忆或调用 API。入口使用加粗光圈、柔和呼吸效果和带箭头的文字提示；提示不拦截点击，随滚动/缩放重新定位，系统要求减少动画时关闭呼吸效果。神经链接依次指向 Sully 卡片、发消息按钮；记忆开关依次指向尚未开启的开关。生成按钮只标识位置，不引导点击。

实名认证要求依据硅基流动[官方公告](https://docs.siliconflow.cn/docs/release-notes/overview)；权益、价格以服务商为准。

实现：`components/FirstUseGuide.tsx`、`utils/firstUseGuide.ts`。回归测试：`utils/firstUseGuide.test.ts`，覆盖老用户不弹、刷新续接、配置/开关门禁、桌面跳转时序和不点击生成。
